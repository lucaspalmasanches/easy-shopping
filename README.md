# Easy Shopping 🛍️

![Status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)

## Sobre o Projeto ✨

Este é um projeto desenvolvido como parte do meu aprendizado no [DevClub](https://www.devclub.com.br/). O "Easy Shopping" é uma **interface de e-commerce responsiva**, focada em demonstrar habilidades de construção de layout moderno e adaptável para diferentes dispositivos, utilizando HTML e CSS.

Com este projeto, busco aplicar as melhores práticas de desenvolvimento front-end e solidificar meus conhecimentos em estruturação e estilização web.
